# Rock Paper Scissors

Best-of-5 Rock Paper Scissors game built with React 18 and Vite.

## Features

- Rock, Paper, Scissors with emoji icons (✊✋✌️)
- Best-of-5 format — first to 3 wins
- Instant round feedback with color-coded win/lose/draw
- "Play Again" button when the game ends
- Clean minimal light theme with blue accent

## How to Play

1. Click **Rock**, **Paper**, or **Scissors**
2. The computer picks a random choice
3. Win a round → your score increases
4. First player to **3 wins** takes the game

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build    # production build → dist/
npm run preview  # preview the production build locally
```
